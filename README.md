## Overview

Quality of Terraria bundles dozens of individually configurable quality-of-life improvements including auto-swing for all weapons, void bag auto-pickup, town NPC housing indicator, smart cursor improvements, lock-on for boss targeting, and many more small but impactful enhancements that reduce repetitive actions during long Terraria sessions.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Quality of Terraria** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Auto-Swing** | All weapons gain auto-swing capability for one-button continuous attack |
| **Void Bag Auto-Pickup** | Items overflow directly into the Void Bag when inventory is full |
| **NPC Housing Indicator** | Visual indicators show valid NPC housing placement on the map |
| **Boss Lock-On** | Optional soft lock-on system for smoother boss targeting in combat |
